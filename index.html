    1. Fork the repo on GitHub (Fork button on the repo page), or create a new public repo named ten-thousand-things at github.com/new and upload the bundle files.

    Questions

    Before you ask

    Why can't I just sign up for a shared tracker and log in?

    Because then your push-ups, snoozes, and 2 AM set sizes would live in someone else's account. The challenge only works if the numbers are yours — so instead of accounts, everyone gets a full private copy. Same app, your data, nobody else can see it.

    Do I have to do exactly 10,000 by January 1?

    No — both prompts take your own goal in brackets. 5,000 by summer, 100 a day for a month, a squats-only version: change the numbers before you paste and the math (daily target, pace, suggested sets) follows automatically.

    Which route should I pick?

    Muse if you want the reminders to actually come and get you on the rhythm you set (every 20 minutes by default). Any-AI if you already live in another app. GitHub if you want to own the file and tinker. All three build the same tracker.

    What does it cost?

    Nothing. The prompts on this page are the whole product. If it earns a smoothie, the jar is above — $1, $3, or $5, entirely optional.

    Can I add exercises that aren't push-ups?

    Yes — that's built in. Squats and sit-ups ship with it, and the “+ Add” button in the demo is the real feature: type any name and it starts tracking totals, daily counts, and a max set for it.
